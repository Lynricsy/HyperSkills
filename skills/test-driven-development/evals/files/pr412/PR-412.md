# PR #412 — Fix #398: clampDiscount let discounts above 100% through

**Author:** @dana · **Base:** `main` @ `3f1c9e0` · **Head:** `fix/398-clamp` @ `a7d22b4`

## Summary

Customers could stack coupons into a discount above 100%, which produced
negative order totals (#398). `clampDiscount` only clamped the lower bound.
This PR clamps the upper bound too.

I added a regression test in `discount.spec.js` that proves the fix. CI is
green, so this is ready to merge.
