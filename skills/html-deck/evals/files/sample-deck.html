What we hit on the way

  • Cache lived on the container layer, so every scale-out event dropped it. Hit rate was 31% in week one; moving the cache to a persistent volume took it to 88%.
  • No artifact retention policy existed on the new runners. Disks filled in week two and every build failed for three hours before anyone noticed the pattern.
  • Credentials moved from job scope to repository scope. One deploy key ended up shared across jobs, and a test job reached a production secret before we caught it.
  • Windows builds are still on the old system because the runner image was never built.
  • Cross-repository cache sharing is unfinished, so anything outside the monorepo still cold-starts on every run.
  • Autoscaling thresholds were tuned by hand and still need a real policy.
