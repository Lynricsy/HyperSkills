- google/styleguide (CC-BY-3.0) — https://github.com/google/styleguide @ 3b8822983dc779c498961cc86332a28c07590f64 — paths: docguide/READMEs.md, docguide/best_practices.md, docguide/style.md — README placement and minimum content: the README belongs at the top level of the code it describes rather than inside the documentation directory, every top-level directory of a shipped package has one, and it must contain or point to what the package is for, its points of contact, its status when that status is deprecated or not for general release, how to use it with copyable commands, and links onward.
