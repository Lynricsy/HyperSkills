## Package notes

### packages/events

`EventBus` is a thin wrapper over Node's `EventEmitter`. Emission is
**in-process and fire-and-forget**: there is no persistence, no broker, and no
delivery guarantee. If the process crashes between `emit()` and a handler
completing, the event is gone. There is no outbox table and no dead-letter path.

### packages/api-client

Generated from `openapi.yaml` by `make client`. Both `web/` and `mobile/` import
it. Changing an endpoint means regenerating the client, which changes types both
apps compile against. The generator emits a union type for response bodies;
adding a field is source-breaking for `mobile/` because its strict-mode build
treats the widened union as an error until call sites are updated.

### services/mailer

Synchronous SMTP wrapper: `sendMail()` opens a connection, sends, returns.
No queue, no retry, no idempotency key, no send log. The billing email templates
live here under `services/mailer/templates/` (4 templates, all transactional
receipts). Nothing in this service records what was sent.

### services/worker

Cron-style runner. Jobs are at-least-once: on an unhandled throw the whole job
is retried from the top with the same input. No per-item checkpointing.

### db/migrations

Managed by a forward-only tool. **There are no down migrations.** Reverting a
deploy does not revert the schema; recovery is a new forward migration.
